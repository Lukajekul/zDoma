- **Status rule (UKONS, generic):** any `klic112`/`klicOddelek` → rdece; alerts on 2+ different questions → rdece; on 1 question → rumeno; else zeleno. Weight +2 kg and weight above dry weight are both reasons but count as one alert.
- **T-05:** save `status` as `checkins.triage_status` and `razlogi.map(r => r.besedilo)` as `checkins.reasons`; one `alerts` row per reason when not zeleno. `opombe` ("Brez merilnika tlaka") are for the nurse only and never change the status. Pass `izbranaVprasanja = rehab.questions` and `vrednosti = rehab.patient_values`. `prejsnji` = earlier check-ins (at least the last 3 days). For the 112 screen before saving, use `nujnoPravilo()` from `@/lib/templates` per tap, or `oceniPregled().nujno`.
