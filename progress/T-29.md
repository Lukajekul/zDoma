- **T-05:** answer option order is display order. An option with `steje: false` ("Nimam ga") saves but counts as not done in the ring. `fotografija: true` asks for a wound photo. Questions with `pogostost: "tedensko"` are weekly (stroke mood). Call `nujnoPravilo()` after each tap.
- **T-21:** `privzetoIzbrano: false` questions (post-MI wound/fever) have `opomba: "Samo po operaciji"`. Ask for each `vrednostiPacienta` entry; `ciljniTlak` defaults to 130/80.

- Decided here (to confirm in T-43): measurements (weight, BP, cancer temperature) are `vednoVprasaj`, because copying a reading from yesterday would be fake data.
