## Done
- `/prijava/qr#<davcna>.<token>`: reads the fragment in the browser, removes it from the address bar, signs in as `<davcna>@zdoma.local` with the token as password, opens `/patient`. Clear Slovenian message when the code was replaced.
- Token: 256 random bits (`crypto.randomBytes`, base64url). Copy kept in `patient_qr_tokens` (migration `20261121200000`, applied with approval): RLS on, no policies, service role only. AGENTS.md §6 updated to match (decided with the human).
- `/prijava/listek/[patientId]`: printable prijavni listek (name, big QR, "Hranite kot ključ…"), "Natisni listek", "Nova koda QR" with a confirm step.
- "Nova koda QR": new token, every session deleted (`revoke_user_sessions`), audit_log `qr.rotate`. The proxy now also checks on protected pages that the session still exists, so other devices are logged out at once. When the patient does it themselves, their own device logs back in and shows the new listek.
- Checked end to end against the shared project (staff sees listek, QR scan logs in, unapproved user blocked, rotate, old QR rejected, old phone logged out, patient self-rotate) and the printed QR decodes to the right link. Test users deleted.
