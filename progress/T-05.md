## Done
- `/patient/<rehabId>/pregled`: one question per screen ("Vprašanje 2 od 6"), big one-tap answers, "Prejšnje vprašanje". Questions = the ones chosen for the rehabilitacija (`rehab.questions`, else the template's pre-ticked ones), weekly ones only if not answered in the last 7 days, always-asked first, max 6. Patient values filled in ("Ste včeraj vzeli Furosemid?").
- Weight: 5 buttons around the last weight (template `korak`), else around the target value; "Drugo" opens a number field (20–300 kg).
- "Enako kot včeraj" offered first when yesterday's check-in was green and covers every non-`vednoVprasaj` question; then only the always-asked questions. The server copies yesterday's answers itself.
- Emergency answers (`klic112` / `klicOddelek` rules) show a full-screen "Pokličite 112" / "Takoj pokličite oddelek" with a call button **before anything is saved**, then "Nadaljuj pregled" or "Nazaj – popravi odgovor".
- Questions with `fotografija` ask for an optional wound photo, uploaded to `wound-photos/<rehabId>/…`.
- Save (server action): validates every answer, runs `oceniPregled`, inserts `checkins` (status + reasons) and one `alerts` row per reason when not green. One check-in per day; a second visit shows the end screen.
- End screen: "Shranjeno ✓", "72,4 kg – blizu vaše ciljne teže 72 kg ✓" (only when green; target = the patient value used by the weight's `nadVrednostjo` rule), "Dan 6 od 30", 7-day weight bars, "Sestra bo pogledala vaše podatke" when yellow/red, "Jutri ob 8:00 spet" (`profiles.checkin_time`).
- "Današnji pregled" button on the "Danes" placeholder.
- Checked: planning + triage against the real heart-failure template (demo day 74,5 kg → rumeno, "Teža +2,5 kg v 3 dneh"), all flow paths and the end screen at 390 px / 1440 px with sample data, logged-out redirect. **Not tested against the database** (no `.env.local`, no seed data).
