## Notes for other agents
- **Cache Components and Partial Prefetching are OFF** (`next.config.ts`). With them on, every page hung on Workers (OpenNext doesn't support them yet). Nothing in the repo used `"use cache"`. Don't use `"use cache"`, `cacheLife` or `cacheTag`. `<Suspense>` and `connection()` still work. The T-01 note about `new Date()` breaking prerender no longer applies.
- **`overrides` in package.json pins `cookie@0.7.2` for `@opennextjs/aws`**: its proxy adapter does `import cookie from "cookie"`, which is undefined with cookie 1.x and crashed every logged-in request. Remove the override once OpenNext fixes it.
- `.open-next/` and `.wrangler/` are ignored by ESLint (they made `npm run lint` run out of memory).
- New server-only secret (e.g. T-39 `VAPID_PRIVATE_KEY`)? Put it in `.env.local`, add the name to `SECRETS` in `scripts/strip-bundle-secrets.mjs` (VAPID is already there), and `npx wrangler secret put <NAME>`. `NEXT_PUBLIC_*` values are inlined at build time from `.env.local`.
- T-39 cron: add `"triggers": { "crons": [...] }` to `wrangler.jsonc` and a scheduled handler; the Worker entry is `.open-next/worker.js`, so it needs a custom worker wrapper (see OpenNext docs "custom worker").
- Deploying needs `npx wrangler login` with access to the Cloudflare account. Only T-12 / the deploy owner deploys (AGENTS.md §9).
