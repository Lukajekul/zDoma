## How to use (import from `@/components/shell`)
- `<AppShell title="Danes" back="/patient">…</AppShell>`: every screen. Shows "Nazaj" + big title in a centred column (max-w-xl; `wide` = max-w-6xl for staff dashboards). `back`: a path links there (preferred: a fixed parent page); omitted = browser back; `false` hides it, only for a top-level home screen.
- `<BigButton href="/x">Text</BigButton>` or `<BigButton onClick={…}>`: full-width, 64 px+ high, `text-xl`. `variant`: `primary` (default) / `secondary` / `success` / `danger` (use for "Pokličite 112"). `icon={<Check />}` is decorative; the text label is always shown. `bigButtonClass(variant)` gives the classes for a custom element (e.g. a form submit wrapper).
- `<StatusBadge status="zeleno" | "rumeno" | "rdece" />`: word + colour + icon, e.g. "Rdeče – potrebna pozornost". `short` = word only (dashboard rows), `label` overrides the meaning text.
- `<BackButton href? />`: only if you build a screen without AppShell.
- `src/lib/format.ts`: `formatDate` ("21. 11. 2026"), `formatTime` ("8:00"), `formatLongDate` ("sobota, 21. november"), `formatNumber` ("74,5"), `todayLjubljana()` ("2026-11-21"), `TIME_ZONE`. All use `Europe/Ljubljana`.
- Tailwind colours available: `bg-status-zeleno(-bg)`, `bg-status-rumeno(-bg)`, `bg-status-rdece(-bg)` (and `text-`/`border-`).
